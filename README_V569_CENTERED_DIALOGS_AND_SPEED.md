# Staff Planner v569 — หน้าต่างกลางจอและเปิดแอพเร็วขึ้น

ฐาน: v568 Consult + Release Notices ที่แนบมา

## สิ่งที่ปรับ

- ข้อความแจ้งเตือนที่เคยเป็น `alert` สีเทาของเบราว์เซอร์เปลี่ยนเป็นหน้าต่างรับทราบกลางแอพ พร้อมรองรับการกด Enter/Escape และอ่านข้อความด้วยอุปกรณ์ช่วยการเข้าถึง
- งานยืนยันรีเซ็ตยอด, ลบตารางแพทย์, ใช้ค่า Slot และแก้ข้อความ Donor Helper ที่เคยใช้ `confirm`/`prompt` ของเบราว์เซอร์ เปลี่ยนเป็นหน้าต่างกลางแอพ; กดปิด/แตะพื้นหลัง/Escape แล้วระบบยกเลิกคำยืนยันได้จริง
- CSS 17 ไฟล์รวมเหลือ 1 ไฟล์ และ JavaScript ที่หน้าแรกเรียก 223 ไฟล์เหลือ 14 ไฟล์ โดยคงลำดับเดิมและเก็บไฟล์ต้นฉบับทุกไฟล์ไว้ใน FULL
- ข้อมูลแต่ละหน้าที่ไม่ต้องรอรายชื่อเจ้าหน้าที่เริ่มโหลดพร้อมกัน และแคชที่ยังใช้ได้ไม่บังคับให้วาดหน้าใหม่ซ้ำ
- ไฟล์แอพแบบมีเลขเวอร์ชันใช้แคชของ PWA เพื่อลดการรอเครือข่ายเมื่อเปิดซ้ำ; HTML ยังตรวจเวอร์ชันใหม่จากเครือข่าย
- อัปเดตประกาศในแอพเป็น v569 ทุกบัญชีที่ยังไม่รับทราบเวอร์ชันนี้จะเห็นเมื่อเปิดแอพ

## วิธีอัปเดต GitHub Pages

1. เก็บ ZIP BACKUP v568 ไว้ก่อน
2. แตก `UPDATE ONLY` แล้วอัปโหลด **ไฟล์ด้านใน** ไปที่ root เดิมของ GitHub โดยให้ทับไฟล์ชื่อเดียวกัน (อย่าอัปโหลด ZIP เป็นไฟล์เดียว)
3. รอ GitHub Pages ปรับหน้า จากนั้นปิดและเปิดแอพใหม่ ถ้าเป็น PWA บนมือถือให้ปิดแอพจากหน้ารายการแอพที่เปิดค้างแล้วเปิดอีกครั้ง
4. ทดสอบเปิดหน้าภาพรวม, ตารางแพทย์, ยืนยันที่มีปุ่มตกลง/ยกเลิก และเมนูที่ใช้บ่อย

`FULL` มีซอร์สทั้งหมดและไฟล์ที่รวมแล้ว แต่ยังไม่บรรจุ `config.js` ที่เป็นค่าตั้งค่าส่วนตัว เช่นเดียวกับ ZIP v568 เดิม ถ้าจะติดตั้งใหม่ต้องนำ `config.js` ที่ใช้งานอยู่จากแหล่งเดิมมาใส่ด้วย

ไม่ต้องรัน SQL เพิ่มสำหรับ v569 ถ้าฐาน v568 ยังไม่ได้รัน SQL ของการจัดการ Consult ให้ทำตาม README v568 เดิมก่อน

เมื่อแก้ source patch ในรุ่นถัดไป ให้ปรับ `asset-manifest-v569.json`, รัน `python3 build_v569_assets.py`, และเปลี่ยนเลขเวอร์ชัน URL ของ bundle ใน `index.html`/แคช `sw.js` เพื่อไม่ให้มือถือใช้ไฟล์เก่า
