# Minimum Stock v2.6.0 — วิเคราะห์ผลถุงเลือดจากการออกหน่วย

## สิ่งที่เพิ่มในรุ่นนี้

เพิ่มเมนูใหม่ **“📈 วิเคราะห์ผลถุงเลือดออกหน่วย”** โดยใช้ไฟล์ Excel เดียวกับหน้า Upload File เดิม เมื่ออัปโหลดสำเร็จ ระบบจะคำนวณและบันทึกรายงานใหม่ให้อัตโนมัติ ไม่ต้องอัปโหลดไฟล์ซ้ำ

รายงานใหม่นี้แยกชุดข้อมูลและฟังก์ชันคำนวณออกจาก `calculateMinimumStock()` เดิม จึงไม่แก้กติกาของ Minimum Stock, Expiry Risk, Mobile Unit Planning หรือการจัดกลุ่ม TRC/CNMI ใน Dashboard เดิม

## กติกาแหล่งรับเข้า

- **กาชาดไทย**: `DonateSource = ศูนย์บริการโลหิตแห่งชาติ สภากาชาดไทย`
- **หาเอง/ออกหน่วย**: DonateSource อื่นที่ไม่ใช่กาชาด และไม่ใช่แหล่งทดสอบ/แหล่งที่ระบบเดิมตัดออก
- **ไม่ระบุ/ต้องตรวจสอบ**: DonateSource ว่าง หรือ BagNumber เดียวมี DonateSource มากกว่า 1 ค่า รายการกลุ่มนี้จะแสดงให้ตรวจสอบ แต่ไม่นำไปคำนวณยอดรวม
- เก็บและแสดงชื่อ `DonateSource` เดิมเป็นจุดออกหน่วย ไม่ใช้ `Location` แทน

แหล่งที่ตัดออกตามระบบเดิม ได้แก่

- `External Quality Assessment (EQA)`
- `Test สอนแพทย์ พยาบาล`
- `ห้องรับบริจาคโลหิต รามาธิบดีจักรีนฤบดินทร์ (1B6)`

## กติกาผลลัพธ์รายถุง

ระบบใช้ `BagNumber` เป็นตัวระบุหลัก และรวม BagNumber ซ้ำให้เหลือหนึ่งถุง

- **นำไปใช้/จ่ายออก**: พบ `Status = Released`
- **ทิ้ง/ทำลาย**: พบสถานะทิ้ง/ทำลาย/หมดอายุ/ไม่ผ่านเกณฑ์ หรือมีค่าใน `DestroyReason`
- **ยังไม่ทราบผล/คงเหลือ/สถานะอื่น**: ไม่เข้าเงื่อนไขด้านบน
- **ข้อมูลขัดแย้ง ต้องตรวจสอบ**: ถุงเดียวพบทั้งหลักฐาน Released และหลักฐานทิ้ง/ทำลาย ระบบไม่นับซ้ำในยอดใช้หรือยอดทิ้ง
- ถุงรับเข้าต้องมี `DateStockIn` ที่อ่านเป็นวันที่ได้

## คอลัมน์ที่ต้องมีใน Excel

ระบบตรวจสอบก่อนล้างข้อมูลเดิมและก่อนคำนวณ โดยต้องมีคอลัมน์ต่อไปนี้

```text
BagNumber
ProductType
DonateSource
DateStockIn
DateStockOut
Status
DestroyReason
```

`BloodGroup` และ `Rh` เป็นคอลัมน์เสริม หากมี ระบบจะเปิดตัวกรองให้ใช้งาน

หากพบคอลัมน์ขาด, BagNumber ซ้ำ, วันที่ผิด, Status ไม่รู้จัก หรือ DonateSource ต้องตรวจสอบ ระบบจะแจ้งเตือนก่อนดำเนินการต่อ ข้อมูลเดิมจะยังไม่ถูกล้างจนกดตกลง

## ความสามารถของรายงาน

- กรองช่วง DateStockIn, เดือน/ปี, กลุ่มแหล่งรับเข้า, DonateSource, ProductType, Blood Group และ Rh
- แสดงจำนวนรับเข้า หาเอง กาชาด ใช้ ทิ้ง คงเหลือ/ไม่ทราบผล และข้อมูลขัดแย้ง
- คำนวณร้อยละใช้และร้อยละทิ้งจากจำนวนรับเข้าตามตัวกรองปัจจุบัน
- ตารางสรุปรายจุด เรียงจากจำนวนรับเข้าสูงสุด
- เปิดรายละเอียดรายถุงของแต่ละจุด
- กราฟเปรียบเทียบหาเองกับกาชาด กราฟรายจุด และกราฟร้อยละทิ้ง
- ส่งออก CSV, Excel, PNG และ PDF/พิมพ์

หมายเหตุ: ปุ่ม PDF/พิมพ์จะเปิดหน้าต่างพิมพ์ของ Browser ให้เลือก **Save as PDF** ส่วน PNG ใช้ไลบรารี `html2canvas` จาก CDN จึงต้องเชื่อมต่ออินเทอร์เน็ตในครั้งที่ใช้งาน

## วิธีอัปเดต GitHub แบบ Update Only

1. แตกไฟล์ `Minimum-Stock-v2_6_0-Mobile-Outcome-UPDATE-ONLY.zip`
2. เข้า GitHub Repository `Minimum-Stock`
3. กด **Add file → Upload files**
4. ลากไฟล์ทั้งหมดจาก ZIP ไปวาง โดยให้ทับไฟล์ชื่อเดิม
5. กด **Commit changes**
6. รอ GitHub Pages Deploy สำเร็จ
7. เปิดเว็บด้วยลิงก์นี้หนึ่งครั้งเพื่อบังคับโหลดเวอร์ชันใหม่

```text
https://transfusionbb-cnmi.github.io/Minimum-Stock/?fresh=1
```

8. เข้า Upload File และอัปโหลด Excel ล่าสุดอีกครั้ง
9. เปิดเมนู **📈 วิเคราะห์ผลถุงเลือดออกหน่วย** เพื่อตรวจรายงาน
